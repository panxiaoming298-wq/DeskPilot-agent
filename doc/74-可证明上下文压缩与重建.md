# 阶段 74：可证明上下文压缩与重建

阶段 74 在 ContextManifest 和长期记忆真值边界之上增加确定性 `CompactionSnapshot`。快照是可失效、可重建的派生视图，不是 Task、Event、Policy、Approval、Tool receipt、verified evidence 或长期记忆的真值。

## 已完成

- 新增 `CompactionSnapshot`、完整 `CompactionSourceRef`、逐字段 `CompactionCoverageItem` 和 parent lineage。
- 新增 `0035_context_compaction` migration，分别保存 snapshot、source refs 和 coverage items。
- v1 确定性提取 Task Contract 目标/约束、Working Memory 目标/约束/决定/未决问题/Artifact 引用，以及 verified evidence 和 active memory 引用。
- 相同 task/source/version/digest/parent/compressor 输入返回稳定 snapshot ID、source-set digest 和 snapshot digest。
- 不把上一代摘要作为新一代来源；rebuild 始终展平到原始 source refs，parent 只记录血缘。
- 每次读取、重建和 Context 使用前重新核验 source status、版本与 digest。消息/记忆删除、长期记忆失效、活动 Contract 版本变化或来源篡改都会使快照 `stale`。
- Task Contract 目标与用户临时目标不一致时快照进入 `conflict`，不会用于 Context 压缩。
- Context 超预算时只替换已被 coverage 完整表示的 Working Memory；Task Contract、Handoff、verified Claim、外部 PageSnapshot 和长期记忆仍保留原有边界。
- 压缩后重新计算 Provider Egress 决策和最终 ModelRequest digest。敏感快照不能发送给 cloud Provider。
- 新增创建、列表、详情和 rebuild API，并新增阶段 74 独立 CI gate。

## API

```text
POST /api/v1/tasks/{task_id}/compaction-snapshots
GET  /api/v1/tasks/{task_id}/compaction-snapshots
GET  /api/v1/compaction-snapshots/{snapshot_id}
POST /api/v1/compaction-snapshots/{snapshot_id}:rebuild
```

响应直接提供结构化字段、完整 source chain、coverage/conflict/stale 状态、classification、parent 和所有证明摘要，可用于后续统一工作台展示压缩前后来源与保留内容。

## 真值与授权边界

- Snapshot 的 `authority_class=derived`，在 Prompt 中明确低于当前指令、Task Contract、Policy、Approval、Tool receipt、unknown outcome 和 verified evidence。
- 压缩不会生成 verified edge，不会改变 execution node 状态，也不会写 active 长期记忆。
- 权限、审批、Tool unknown 和外部 Evidence 不会仅靠快照保存；压缩只能减少可证明覆盖的非权威 Working Memory 重复项。
- source 删除只使快照失效，不删除历史 ContextManifest、TaskEvent、Approval、Tool receipt 或 Provider 已接收内容。

## 为什么 v1 没有模型摘要

`narrative_summary` 在 v1 固定为 `null`。当前阶段没有必要引入额外模型调用、Prompt 版本和 hallucination verifier；确定性结构化字段已经能完成预算触发、稳定重建和关键约束 100% 保留的最小闭环。未来只有在非权威叙述成为实测瓶颈时，才增加本地优先模型摘要，并要求独立 coverage/contradiction 验证。

## 验收覆盖

- 长上下文 fixture 中重复 Working Memory 会触发压缩；路径、否定约束、数字和未决问题仍进入实际 ModelRequest。
- 相同输入重复创建稳定；active snapshot 可生成带 parent 的 rebuild。
- Working Memory 删除和活动 Task Contract amendment 会使旧 snapshot stale。
- 目标冲突可见且快照不参与压缩。
- structured fields 或持久化证明篡改返回 `COMPACTION_PROOF_REJECTED`。
- `0035` 空库升级、metadata check、降级和再次升级通过。

## 明确非目标

- 不引入 LLM narrative summarizer 或保存私有思维链。
- 不压缩 verified Claim、PageSnapshot、Tool/Approval/Policy 真值。
- 不引入 embedding、向量数据库或新的 Context 真值。
- 不实现统一 Conversation/Research/Artifact 前端；该控制面属于后续工作。
