# 阶段 66：二十黄金任务与版本化趋势报告

## 1. 目标与边界

本阶段把阶段 65 的三个黄金案例扩展为二十个固定案例，并增加可下载的 `deskpilot.evaluation-report.v1`、跨运行趋势、运行/Case p50/p95 和失败分类聚合。套件仍由应用包内 YAML 唯一提供，不增加上传、URL、Shell、动态 Python 或任意 handler 入口。

套件升级为 `deskpilot.resilience-safety` version 2。旧运行继续可验证和查询，但因为 suite digest 已改变，不能冒充 version 2 Replay；新 Replay 仍会重新执行全部二十个场景并比较语义摘要。

## 2. 二十个固定案例

`golden_resilience_v2.yaml` 包含八类白名单场景：

- 六个 MCP 文本指标案例，覆盖 ASCII、多行、Unicode、数字、标点和空白；
- 三个知识来源变化案例，分别命中 recovery、evidence、local 后证明旧 Citation 不泄漏；
- MCP bundle 注册后篡改拒绝，以及空文本、额外字段两种输入拒绝；
- 三个固定异常 MCP Server，分别返回错误协议版本、错误 JSON-RPC ID 和非法 JSON；
- Model Gateway 429 一次后恢复，以及达到尝试预算后稳定返回 `MODEL_RATE_LIMITED`；
- Runner Supervisor 单次/双次崩溃后的 generation 递增与恢复；
- WebSocket live stream 收到 disconnect 后退出且不继续发送事件。

其中十一项标记为 safety case。MCP 异常 Server 是仓库内固定 fixture，由同一短生命周期、isolated 环境、临时 cwd Host 启动；不是用户提供的进程。429 使用固定本地 Provider 注入 Gateway 的真实 retry/budget 路径。Runner 案例注入确定性 client generation 失败以验证真实 Supervisor 恢复状态机，不等同于阶段 55 已覆盖的 OS 进程强杀。WebSocket 案例验证流处理协程，不宣称覆盖真实网络分区。

## 3. 版本化报告与趋势

新增两个受保护、`no-store` API：

- `GET /api/v1/evaluations/reports/latest`：读取最近 1～100 个运行并返回报告；
- `GET /api/v1/evaluations/reports/latest:export`：返回同一 JSON，并设置固定 v1 下载文件名。

报告生成前逐 Run 复核 result manifest、计数投影、Trace 投影和完整 hash chain。任何一条历史证据损坏都会使整个报告返回 `EVALUATION_PROOF_REJECTED`，不会跳过坏样本后给出貌似可信的趋势。

报告记录窗口内运行通过率、通过/失败运行数、运行耗时 p50/p95、Case 耗时 p50/p95、稳定错误码计数和按时间升序的趋势点。分位数使用确定性 nearest-rank 算法，小样本不插值。报告 material 使用 canonical JSON 形成 `report_digest`；`as_of` 绑定窗口内最新运行完成时间，不使用每次请求变化的生成时间，因此相同证据窗口产生相同摘要。

## 4. 前端

“评测与 Trace”面板现在明确显示固定二十项套件，并增加报告 v1 下载、运行/Case p50/p95、失败运行数、失败分类、内容摘要和运行趋势。浏览器只展示服务端复核后的报告，不重算 Trace 真值或分位数。

## 5. 验证与下一步

自动化覆盖二十项首次运行、完整 Replay、四类故障场景存在性、趋势顺序、报告摘要/下载头、失败分类聚合，以及 Trace 篡改导致报告整体失败关闭。最终门禁：Ruff 全仓通过；mypy 160 个生产源码通过；pytest 426 collected、414 passed、12 skipped、1 条既有第三方 warning；Alembic `0029` head/check 与 migration 回归通过；`uv lock --check` 通过；前端 20 文件/139 项测试、type-check 和 production build 通过。

下一阶段进入 OpenTelemetry 最小闭环：为任务、模型、工具、MCP 与评测建立不含正文的 trace/span/metric 关联，提供本地导出和 trace ID 查询，并把黄金报告接入显式版本化回归基线门禁；仍不把 prompt、文件正文、凭据或 MCP 原始内容写入普通 span 属性。
